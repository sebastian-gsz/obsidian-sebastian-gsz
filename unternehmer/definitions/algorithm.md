Secuencia finita de instrucciones para resolver un problema.

* **Faceta de programación**: El algoritmo define la lógica de ejecución, las estructuras de control (bucles, condicionales) y el manejo de datos.
* **Faceta de ciencia de datos**: Son las fórmulas matemáticas y modelos estadísticos (como redes neuronales) que permiten realizar inferencias a partir de datos.
* **Propósito**: Automatizar la resolución de problemas mediante pasos claros, precisos y ejecutables por una máquina.
