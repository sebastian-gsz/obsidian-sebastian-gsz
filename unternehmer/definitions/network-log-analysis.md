Es el proceso de recolección, normalización y examen crítico de los registros (logs) generados por los diversos dispositivos de infraestructura de red (firewalls, WAFs, balanceadores, routers, switches y proxies).

* **Finalidad**: Identificar patrones de comportamiento que se desvíen de la línea base operativa. Este análisis permite la detección temprana de actividades maliciosas como el escaneo de puertos, ataques de fuerza bruta, intentos de exfiltración de datos o el uso de protocolos no autorizados.
* **Componente de observabilidad**: En entornos modernos, este proceso suele automatizarse mediante soluciones SIEM (Security Information and Event Management), que correlacionan los registros de red con otras fuentes de datos para proporcionar una visión completa de la postura de seguridad.
