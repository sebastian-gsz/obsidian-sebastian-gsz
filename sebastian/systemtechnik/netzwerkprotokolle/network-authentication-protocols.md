-  **AAA: Authentication, Authorization and Accounting**

	-  **RADIUS** — **Remote Authentication Dial-In User Service**

		Utilizado principalmente para la **autenticación**, **autorización** y **contabilidad** de usuarios en redes, especialmente en servicios de acceso remoto, como conexiones VPN, redes inalámbricas o conexiones a través de acceso telefónico.

		**Funciones clave de RADIUS**:

		-  **Autenticación (A):** Verifica la identidad de los usuarios mediante credenciales, como un nombre de usuario y una contraseña.
		-  **Autorización (A):** Define los permisos de acceso de los usuarios, es decir, qué recursos pueden utilizar después de autenticarse.
		-  **Contabilidad (C):** Rastrea las actividades del usuario, como la duración de la sesión o los recursos utilizados, para facturación o auditoría.

		**Ventajas**:

		-  Centralización de la autenticación y autorización.
		-  Soporte para servicios de contabilidad.

		**Desventajas**:

		-  Limitaciones en políticas complejas de control de acceso.

	-  **LDAP** — **Lightweight Directory Access Protocol**

		**Ventajas**:

		-  Estructura jerárquica para gestionar cuentas de usuario y permisos.
		-  Integración con soluciones VPN para autenticación de usuarios.

		**Desventajas**:

		-  Complejidad en la gestión de servidores LDAP.

	-  **TACACS+** — **Terminal Access Controller Access-Control System Plus**

		**Ventajas**:

		-  Separación de funciones de autenticación, autorización y contabilidad.
		-  Mayor control sobre el acceso a recursos de red.

		**Desventajas**:

		-  Configuración y gestión más complejas en comparación con RADIUS y LDAP.
		-  Soporte limitado para autenticación y autorización centralizadas.

	-  **EAP-TLS** — **Protocolo de Autenticación Extensible**
