
Un equilibrador de carga de aplicación de Elastic Load Balancing (ELB) es un servicio de equilibrio de carga completamente administrado para el tráfico HTTP y HTTPS. Está optimizado para enrutar las solicitudes entrantes a varios destinos, como instancias de EC2, en varias zonas de disponibilidad. Funciona en la capa 7 del modelo de interconexión de sistemas abiertos (Open Systems Interconnection, OSI), lo que significa que puede tomar decisiones de enrutamiento en la capa de aplicación. 

Debido a que funciona en la capa de aplicación, un equilibrador de carga de aplicación puede admitir características más avanzadas, como el enrutamiento basado en rutas y hosts. También puede admitir el enrutamiento basado en encabezados HTTP estándar o personalizados, métodos, parámetros de consulta y direcciones IP de origen.
