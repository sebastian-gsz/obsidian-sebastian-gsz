Software que, aunque no siempre calificado como malware destructivo, se instala en un sistema de forma subrepticia o engañosa, afectando la experiencia del usuario y la seguridad.

* **Impacto**: Estas aplicaciones suelen incluir barras de herramientas (toolbars) no solicitadas, motores de búsqueda modificados o software que monitorea la actividad del usuario para fines comerciales. Suponen un riesgo porque suelen introducir vulnerabilidades adicionales y degradan el rendimiento del sistema operativo.
