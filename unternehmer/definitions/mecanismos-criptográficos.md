Conjunto de herramientas para proteger la información:

* **Cifrado (Encriptación)**: Conversión de datos legibles a formato codificado.
* **Cifrado Simétrico**: Utiliza una única clave tanto para cifrar como para descifrar.
* **Cifrado Asimétrico (Clave Pública)**: Utiliza dos claves: una pública (para cifrar) y una privada (para descifrar).
* **Cifrado AES**: Algoritmo estándar para bloques de texto; AES-256 es la variante actual altamente segura.
* **PKI (Infraestructura de Clave Pública)**: Sistema que gestiona certificados digitales y claves.
