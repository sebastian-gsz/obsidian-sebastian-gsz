El Machine Learning es una rama de la inteligencia artificial centrada en el desarrollo de algoritmos que permiten a los sistemas aprender patrones y mejorar su rendimiento mediante la exposición a datos, eliminando la necesidad de programar reglas explícitas para cada escenario posible.

#### Funcionamiento: Inferencia vs. Programación

A diferencia del desarrollo de software tradicional, donde un ingeniero define la lógica de negocio mediante sentencias condicionales (`if-then-else`) para cubrir cada caso, el Machine Learning invierte este paradigma:

-  **Entrada de datos:** Se alimenta al sistema con grandes volúmenes de información (imágenes, texto, series temporales).
-  **Entrenamiento:** El algoritmo analiza estadísticamente los datos para identificar correlaciones y patrones ocultos.
-  **Modelo:** El resultado es un "modelo" que ha inferido las reglas subyacentes y es capaz de aplicarlas sobre datos nuevos no vistos previamente.

#### Tipología de resultados

Los modelos de aprendizaje automático permiten implementar sistemas con capacidades avanzadas:

-  **Descriptivas:** Resumen, visualización y explicación de datos históricos para entender qué ocurrió.
-  **Predictivas:** Pronósticos de eventos futuros o estimación de valores basados en la extrapolación de patrones aprendidos (ej. regresiones).
-  **Prescriptivas:** Sistemas de recomendación que sugieren acciones óptimas para alcanzar un objetivo específico (ej. optimización de rutas, sugerencias de productos).
