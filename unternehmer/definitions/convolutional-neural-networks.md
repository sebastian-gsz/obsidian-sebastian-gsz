Las redes neuronales convolucionales (CNN) son una arquitectura de aprendizaje profundo especializada en el procesamiento de datos que poseen una estructura de rejilla, siendo las imágenes su aplicación más prominente. Su diseño permite capturar jerarquías de características espaciales de manera automática y eficiente.

El funcionamiento fundamental de una CNN se basa en la aplicación de filtros, conocidos como convoluciones, sobre la imagen de entrada para detectar patrones espaciales, desde bordes simples hasta formas complejas. En aplicaciones como el reconocimiento facial, la red aprende a identificar rasgos únicos —tales como ojos, nariz y contornos— de forma jerárquica, comparando estas representaciones aprendidas contra una base de datos para verificar la identidad de un individuo.

-  **Estructura de rejilla:** Están optimizadas para manejar datos con dimensiones espaciales, lo que facilita el análisis de píxeles en imágenes.
-  **Procesamiento mediante convoluciones:** Utilizan filtros matemáticos que se deslizan sobre la imagen para extraer características relevantes.
-  **Aprendizaje jerárquico:** Permiten que el modelo identifique primero rasgos elementales y los combine progresivamente para reconocer objetos o estructuras completas.
-  **Aplicación en identificación:** Su capacidad para extraer rasgos faciales únicos las hace idóneas para sistemas de verificación de identidad de alta precisión.
