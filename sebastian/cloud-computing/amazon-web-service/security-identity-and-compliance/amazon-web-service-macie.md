
Macie emplea aprendizaje automático para descubrir, clasificar y proteger de forma automática información confidencial en AWS, como datos de identificación personal (PII) o propiedad intelectual. Además, el servicio ofrece paneles de control y alertas que brindan visibilidad sobre cómo se accede a estos datos y los traslados que se realizan con ellos.
