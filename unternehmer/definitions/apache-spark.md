Motor de computación distribuida de código abierto, optimizado para el procesamiento de datos a gran escala (Big Data). Destaca por su capacidad para manejar volúmenes masivos de información con una velocidad significativamente superior a marcos tradicionales como MapReduce.

*  **Arquitectura de rendimiento**: Su característica distintiva es el procesamiento en memoria (in-memory computing), que evita la escritura constante a disco, acelerando drásticamente las iteraciones en tareas de ciencia de datos.
*  **Versatilidad ecosistémica**:
  
    * **Multi-idioma**: Soporte nativo para Python (PySpark), SQL, Scala, Java y R.
    * **Flujo mixto**: Capaz de manejar procesamiento por lotes (batch) y streaming en tiempo real en una misma plataforma.
    * **Escalabilidad**: Diseñado para realizar análisis exploratorios sobre conjuntos de datos de escala petabyte, distribuyendo la carga de trabajo de manera eficiente a través de clústeres de miles de nodos.
