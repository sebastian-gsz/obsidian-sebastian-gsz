Una MicroVM (o máquina virtual ligera) es una versión extremadamente optimizada de una máquina virtual. Mientras que una máquina virtual tradicional emula un hardware completo y carga un sistema operativo pesado, una Microvm reduce esa capa al mínimo indispensable para ejecutar una única carga de trabajo, proporcionando un aislamiento fuerte con un consumo de recursos muy bajo.
