
Herramienta de sincronización de identidades. GCDS (**Google Cloud Directory Sync**) es una **aplicación de escritorio** (un programa) que debes descargar e instalar en un servidor dentro de tu **entorno local (on-premises)** o en una máquina virtual que tenga acceso a tu Active Directory (AD) o servidor LDAP.
