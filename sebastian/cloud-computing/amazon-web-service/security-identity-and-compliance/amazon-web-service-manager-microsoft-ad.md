
Permite ejecutar el directorio activo de Microsoft (Active Directory) como un servicio totalmente administrado en la nube de AWS. Facilita la integración de aplicaciones y recursos de Windows con AWS (como servidores virtuales o bases de datos) utilizando las credenciales corporativas existentes, sin necesidad de desplegar ni mantener controladores de dominio propios.
