Método analítico utilizado para examinar y evaluar la diferencia entre el estado actual de un proceso o rendimiento y el estado futuro deseado (objetivo).

* **Aplicación**: Permite identificar de manera precisa dónde se encuentran las brechas operativas o funcionales y definir las oportunidades de mejora necesarias para alcanzar los estándares de excelencia requeridos por la organización.
