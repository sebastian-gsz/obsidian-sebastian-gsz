Proceso de aprendizaje donde el sistema recibe datos sin etiquetas ni respuestas correctas predefinidas. El algoritmo debe explorar los datos de forma autónoma para descubrir estructuras ocultas, agrupaciones (clustering) o asociaciones latentes.

*  **Aplicación en redes**: Es la herramienta principal para la detección de anomalías (anomaly detection). Dado que el sistema aprende qué es el comportamiento "normal" sin intervención humana, puede disparar alertas ante patrones de tráfico inusuales que se desvían de dicha norma, resultando eficaz para descubrir amenazas desconocidas (Zero-day) sin necesidad de firmas previas.
