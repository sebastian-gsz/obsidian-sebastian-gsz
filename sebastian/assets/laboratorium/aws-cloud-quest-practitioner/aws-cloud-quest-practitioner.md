-  **Creación de website static for S3**

	![[convert-simple-storage-service-into-static-website.png]]
	![[creation-website-static-for-s3.mp4]]
		1. Nos dirigimos a **``S3``**. Accedemos al bucket: **`website-bucket-5b3f80f0`**
		2. Renombramos **``text.html``** > **``error.html``**
			![[convert-simple-storage-service-into-static-website-1.png]]
		3. Dentro del bucket: **``Propiedades``** > **``Alojamiento de sitios web estáticos``** > **``Editar``** 
			![[convert-simple-storage-service-into-static-website-2.png]]
		4. Guardamos los cambios y copiamos la URL proporcionada por S3
			![[convert-simple-storage-service-into-static-website-3.png]]
