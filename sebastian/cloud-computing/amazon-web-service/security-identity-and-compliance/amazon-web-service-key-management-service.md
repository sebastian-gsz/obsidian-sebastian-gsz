
Key Management Service (KMS) es un servicio totalmente administrado que simplifica la creación y el control de las claves de cifrado sin la necesidad de gestionar tu propio módulo de seguridad de hardware (HSM). Este servicio permite integrar capacidades criptográficas directamente en el código de tus aplicaciones o mediante productos compatibles como S3 y CloudTrail, facilitando el cumplimiento de los requisitos normativos, de auditoría y de conformidad.
