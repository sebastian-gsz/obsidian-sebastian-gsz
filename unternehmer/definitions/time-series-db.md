Optimizada para almacenar secuencias de datos indexadas por tiempo (timestamps).

* **Faceta de ingesta**: Diseñada para manejar altísimos volúmenes de escritura de forma secuencial.
* **Faceta de consulta**: Altamente eficiente para operaciones de agregación sobre intervalos de tiempo (promedios, tendencias, mínimos/máximos).
* **Propósito**: Monitoreo de infraestructura (CPU/RAM), sensores IoT, registros financieros de alta frecuencia.
