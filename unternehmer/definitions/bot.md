Un programa informático diseñado para ejecutar tareas de forma automática y repetitiva, operando frecuentemente sin la intervención directa o el consentimiento explícito del usuario.

### Puntos clave

-  **Faceta de ciberseguridad**: En entornos maliciosos, un bot actúa como software implantado en un sistema comprometido, permitiendo que un atacante ejecute comandos de forma remota y controle el dispositivo.
-   **Faceta de automatización**: El uso de bots no es inherentemente malicioso; existen aplicaciones legítimas, como los bots de búsqueda para indexación web o los asistentes de atención al cliente.
-   **Distinción operativa**: La diferencia fundamental entre un bot legítimo y una amenaza reside en la intención del operador y el consentimiento del propietario del sistema afectado.
-   **Propósito**: Ejecutar acciones a gran escala, ya sea para fines operativos legítimos o para orquestar actividades ilícitas dentro de una red comprometida.
