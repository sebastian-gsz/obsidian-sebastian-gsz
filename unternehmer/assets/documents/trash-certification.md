	-  **Solutions Architect**

		-  **Fase 1: Fundamentos (Entendiendo la nube)**
		
			Antes de diseñar soluciones, debes comprender el lenguaje y los servicios básicos de Google Cloud.
			
			- **Ruta de aprendizaje de Introducción a Google Cloud 💚**
			- **Certificado de Google Cloud Computing Foundations 💚**
			- **Certificación de Cloud Digital Leader 💚**
		-  **Fase 2: Implementación Técnica (El "cómo" se construye)**
		
			Un arquitecto debe saber cómo se despliegan y operan los recursos. Sin este conocimiento, tus diseños no serán prácticos.
			
			- **Certificación de Associate Cloud Engineer 💚** (Esencial: esta es la base técnica de cualquier arquitecto).
		-  **Fase 3: Diseño y Estrategia (El "núcleo" del rol)**
		
			Esta es la etapa crítica para tu perfil. Aquí aprenderás a tomar decisiones de arquitectura, optimización y diseño de alto nivel.
			
			- **Certificación de Professional Cloud Architect 💚** (El pilar fundamental para tu carrera).
			- **Renovación de la certificación Professional Cloud Architect 💚** (Para mantenerte al día con las mejores prácticas).
		-  **Fase 4: Especialización en Arquitectura**
		
			Un Solutions Architect debe ser capaz de profundizar en áreas específicas según las necesidades del negocio.
			
			- **Hybrid and Multi-Cloud Architect 💚** (Fundamental para arquitecturas modernas de empresa).
			- **Certificación de Professional Network Engineer 💚** (La red es el sistema nervioso de cualquier arquitectura).
			- **Certificación de Professional Database Engineer 💚** (Vital para el diseño de estrategias de datos).
			- **Certificación de Professional Cloud Developer 💚** (Para integrar el desarrollo de software con la arquitectura).
			- **Certificación de Professional Cloud DevOps Engineer 💚** (Para asegurar que tus arquitecturas sean escalables y operables).
		-  **Fase 5: Estrategias de Migración y Optimización**
		
			Como arquitecto, te enfrentarás frecuentemente a escenarios donde debes mover sistemas existentes hacia la nube.
			
			- **Google Cloud Infrastructure for AWS professionals 💚**
			- **Google Cloud Infrastructure for Azure professionals 💚**
			- **Ruta acelerada de Cloud Architect para profesionales de AWS 💚**
			- **Ruta acelerada de Cloud Architect para profesionales de Azure 💚**
		-  **Fase 6: Habilidades Complementarias (Metodologías)**
		
			Un buen arquitecto no solo diseña tecnología, sino que también gestiona el flujo de trabajo y los equipos.
			
			- **Google Project Management Certificate**
			- **Google Agile Essentials**
	-  **Cybersecurity**
	
		-  **Principiante**
		
			- **Google Cybersecurity Certificate:** Programa fundamental para entrar en el sector de la ciberseguridad.
			- **Principiante: Certificado de Google Cloud Cybersecurity 💚:** Introducción específica a los conceptos de seguridad dentro del ecosistema de Google Cloud.
		-  **Intermedio / Técnico**
		
			- **Practicing Zero Trust 💚:** Enfocado en la arquitectura de seguridad moderna sin confianza perimetral.
			- **Ruta de aprendizaje de seguridad de redes 💚:** Especialización en la protección de infraestructuras de red.
			- **Google Security Operations 💚:** Formación práctica en la gestión de operaciones de seguridad.
			- **Google SIEM & SOAR 💚:** Capacitación en herramientas de gestión de eventos e información de seguridad (SIEM) y automatización de respuestas (SOAR).
			- **GDC Air-Gapped Security Operator Fundamentals 💚:** Fundamentos para operar entornos de Google Distributed Cloud altamente seguros y aislados.
		-  **Avanzado / Profesional**
		
			- **Professional Security Operations Engineer Certification 💚:** Certificación de nivel profesional para ingenieros de operaciones de seguridad.
			- **Certificación Professional Security Engineer 💚:** Una de las certificaciones de más alto nivel para arquitectos y especialistas en seguridad de Google Cloud.
			- **DevSecOps 💚:** Integración avanzada de prácticas de seguridad dentro del ciclo de vida de desarrollo de software (CI/CD).
