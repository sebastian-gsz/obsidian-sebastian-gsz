-  **Introducción a Azure Arc**

	-  Azure Arc es una plataforma de administración coherente que simplifica la gobernanza y la administración de entornos complejos y distribuidos en entornos locales, perimetrales y multinube.
	-  Permite administrar servidores, máquinas virtuales, clústeres de Kubernetes y bases de datos como si se ejecutaran en Azure, independientemente de dónde se encuentren los recursos.
	-  Azure Arc admite la administración de varios tipos de recursos, incluyendo servidores y máquinas virtuales, clústeres de Kubernetes, servicios de datos de Azure y SQL Server, y ofrece una experiencia unificada para ver los recursos habilitados para Azure Arc.
	-  Azure Arc es una parte clave del enfoque de nube adaptable de Microsoft, que ayuda a las organizaciones a ejecutar y administrar aplicaciones y servicios en diferentes entornos.
-  **Servicios y funcionalidades de Azure Arc**

	-  Azure Arc ofrece varios servicios, como servidores habilitados para Azure Arc, VMware vSphere habilitado para Azure Arc, System Center Virtual Machine Manager habilitado para Azure Arc y Azure Local, que permiten administrar máquinas virtuales y físicas en diferentes infraestructuras.
	-  Cada servicio de Azure Arc tiene sus propias funcionalidades y se puede elegir el adecuado según las necesidades de la organización, como la administración de máquinas virtuales, la seguridad, la gobernanza y la automatización.
	-  Azure Arc permite la supervisión del rendimiento del sistema operativo y la detección de componentes de la aplicación mediante VM Insights y el agente de Log Analytics.
	-  VMware vSphere habilitado para Azure Arc y SCVMM habilitado para Azure Arc ofrecen funcionalidades específicas y adicionales, como la administración de recursos de TI híbridos y la ejecución de software en Azure VMware Solution.
	-  Azure Local es un sistema operativo de infraestructura hiper convergida que se proporciona como un servicio de Azure, diseñado para hospedar máquinas virtuales y cargas de trabajo en contenedor, y permite la administración de infraestructuras y cargas de trabajo desde Azure.
	-  Las ubicaciones personalizadas en Azure Arc permiten a los administradores controlar el acceso a recursos en un clúster de Kubernetes o en vCenter o Azure Local.
