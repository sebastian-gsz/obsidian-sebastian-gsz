> **Azure Advisor** es un servicio nativo de Azure que **analiza tu suscripción, tus recursos y su configuración** para darte **recomendaciones prácticas** que mejoran tu arquitectura en cinco áreas clave.

1. **Coste**

    -  Detecta máquinas sobredimensionadas.
    -  Señala recursos sin uso.
    -  Sugiere reservas o cambios de SKU para ahorrar.
2. **Seguridad**

    -  Se integra con Defender for Cloud.
    -  Te avisa de configuraciones inseguras o vulnerables.
3. **Fiabilidad (High Availability)**

    -  Te indica si tus recursos no cumplen buenas prácticas de resiliencia.
    -  Ejemplo: VMs sin Availability Set o sin zonas.
4. **Rendimiento**

    -  Detecta cuellos de botella o configuraciones que limitan el rendimiento.
5. **Excelencia operativa**

    -  Recomendaciones sobre gobernanza, monitorización y operaciones.
