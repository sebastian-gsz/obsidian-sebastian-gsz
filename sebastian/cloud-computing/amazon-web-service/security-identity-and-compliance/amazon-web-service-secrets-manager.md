
Secrets Manager centraliza la administración de datos confidenciales —como credenciales de bases de datos, contraseñas y claves de API— para acceder de forma segura a recursos, entornos locales y servicios de terceros. Su arquitectura permite eliminar las credenciales estáticas incrustadas en el código mediante llamadas programáticas a su API, además de ofrecer la capacidad de configurar una rotación automática de los secretos según la programación que se establezca.
