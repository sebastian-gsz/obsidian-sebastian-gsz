-  **Introducción**

	-  **Variables**
	
		En JavaScript, las variables se declaran utilizando tres palabras clave diferentes. Aquí tienes la diferencia rápida:
		
		* **`let`:** Se usa para variables cuyos valores **van a cambiar** con el tiempo (es la forma moderna y recomendada para datos que se actualizan). Tiene ámbito de bloque.
		* **`const`:** Se usa para valores que **nunca van a cambiar** (constantes). Si intentas reasignar su valor después, JavaScript te dará un error. También tiene ámbito de bloque.
		* **`var`:** Es la forma antigua. Hoy en día **se evita** porque tiene un comportamiento confuso con el alcance del código.
		
		💡 **Consejo actual:** Utiliza siempre `const` por defecto, y usa `let` solo cuando sepas que el valor va a cambiar. ¡Evita `var`!
