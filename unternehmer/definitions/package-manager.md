Es un sistema o conjunto de herramientas automatizadas que estandariza el proceso de instalación, actualización, configuración y eliminación de software dentro de un sistema operativo.

* **Función crítica**: Su valor reside en la gestión inteligente de dependencias; el administrador verifica automáticamente que el software a instalar cuente con todas las bibliotecas y componentes necesarios, resolviendo conflictos de versiones sin intervención manual.
* **Ecosistemas comunes**: Incluye gestores a nivel de sistema operativo (como APT, YUM, DNF) y a nivel de lenguaje de programación (como npm para JavaScript, pip para Python o Maven para Java), los cuales facilitan entornos de desarrollo reproducibles y consistentes.
