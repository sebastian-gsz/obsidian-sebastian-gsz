Distribución de Linux de código abierto derivada de las fuentes de Red Hat Enterprise Linux (RHEL).

* **Rol**: Históricamente utilizada como el estándar de facto para servidores empresariales debido a su estabilidad, seguridad y compatibilidad binaria con RHEL.
* **Estatus**: Evolucionó hacia CentOS Stream, posicionándose como una plataforma de desarrollo *upstream* para RHEL.
