Las bases de datos de propósito general están diseñadas para ofrecer un equilibrio entre rendimiento, flexibilidad, integridad y escalabilidad, permitiendo a los desarrolladores modelar una amplia gama de aplicaciones empresariales sin necesidad de cambiar la tecnología subyacente.

**Principales exponentes**

* **PostgreSQL**: Es considerada la base de datos relacional de código abierto más avanzada. Destaca por su extensibilidad, soporte de tipos de datos complejos y cumplimiento estricto de estándares.
* **MySQL / MariaDB**: Son el estándar de facto para aplicaciones web. Ofrecen un alto rendimiento, facilidad de despliegue y una amplia compatibilidad con el ecosistema de desarrollo web.
* **Microsoft SQL Server**: Solución empresarial robusta con una integración profunda en el ecosistema Windows y herramientas de análisis avanzadas.
* **Oracle Database**: Líder en entornos de misión crítica de gran escala, ofreciendo características avanzadas de seguridad, particionamiento y alta disponibilidad.
* **MongoDB**: Aunque comenzó como una base de datos de documentos, ha evolucionado a un modelo multipropósito capaz de gestionar datos no estructurados y semiestructurados con flexibilidad, siendo hoy una opción generalista muy común.

**Características comunes**

* **Versatilidad**: Soportan consultas complejas, actualizaciones transaccionales (ACID) y grandes volúmenes de datos.
* **Ecosistema**: Cuentan con soporte comunitario o comercial extenso, bibliotecas de conexión para casi cualquier lenguaje y herramientas de monitoreo.
* **Escalabilidad**: Ofrecen mecanismos (ya sean verticales u horizontales) para adaptarse al crecimiento de la aplicación a medida que aumentan los datos o los usuarios.
