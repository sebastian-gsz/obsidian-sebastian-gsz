	-  **Píldora HTML** 
	
		HTML (HyperText Markup Language) es el lenguaje que se utiliza para **crear la estructura y el contenido de las páginas web**. Permite que los navegadores interpreten y muestren información como textos, imágenes, vídeos y enlaces.
		
		**Funciones principales de HTML**:
		
		-  **Organizar el contenido** de una página mediante títulos, párrafos, listas, tablas y otros elementos.
		-  **Insertar recursos multimedia** como imágenes, vídeos y audios.
		-  **Crear enlaces** para navegar entre páginas web o secciones de una misma página.
		-  **Servir como base** para otros lenguajes web:
		  
		    -  **CSS**: da estilo y diseño a la página.
		    -  **JavaScript**: añade interactividad y funcionalidades dinámicas.
		
		Todo documento HTML tiene una estructura principal que indica al navegador cómo interpretar y mostrar una página web.
		
		-  **1. `<!DOCTYPE html>`**
		
			-  Indica que el documento está escrito en HTML5.
			-  Ayuda al navegador a interpretar correctamente la página.
		-  **2. `<html>`**
		
			-  Es la etiqueta raíz que contiene todo el contenido de la página.
			-  El atributo `lang="es"` indica que el idioma es español.
		-  **3. `<head>`**
		
			-  Contiene información sobre la página que no se muestra directamente al usuario.
			-  Incluye metadatos, el título y configuraciones.
		-  **4. `<meta charset="UTF-8">`**
		
			-  Permite mostrar correctamente caracteres especiales como ñ, tildes y símbolos.
		-  **5. `<meta name="viewport">`**
		
			-  Hace que la página se adapte correctamente a dispositivos móviles.
		-  **6. `<title>`**
		
			-  Define el título que aparece en la pestaña del navegador.
		-  **7. `<body>`**
		
			-  Contiene todo el contenido visible de la página.
		-  **8. `<h1>`**
		
			-  Representa un encabezado o título principal.
		-  **9. `<p>`**
		
			- Define un párrafo de texto.
	-  **Píldora JavaScript**
	
		Para entender JavaScript sin caer en explicaciones técnicas aburridas, suelo imaginarlo como el **sistema nervioso y muscular** de una página web. Si **HTML** es el esqueleto (la estructura) y **CSS** es la ropa y el maquillaje (el diseño), **JavaScript es lo que le da vida**: le permite moverse, reaccionar y pensar.
		
		**¿Cómo cobra vida una página gracias a JavaScript?**
		
		Imagina que entras a una tienda online o a una red social. Todo lo que ocurre en tiempo real pasa gracias a este lenguaje:
		
		-  **Modifica lo que ves al instante:** Puede cambiar textos, colores o imágenes en plena navegación sin necesidad de que el navegador vuelva a cargar toda la página. Si recibes un mensaje nuevo en WhatsApp Web, aparece ahí mismo de forma mágica.
		-  **Reacciona a lo que haces:** Está atento a cada clic, movimiento de ratón o tecla que presionas. Si haces clic en un botón y salta una ventana emergente, o si despliegas un menú oculto, detrás está JavaScript escuchándote.
		-  **Comprueba tus errores antes de enviarlos:** Cuando rellenas un formulario (como tu contraseña o correo), JavaScript lo revisa al vuelo. Si te has dejado un campo obligatorio o eres menor de edad para registrarte, te avisa antes siquiera de molestar al servidor.
		-  **Mueve las cosas:** Anima elementos, crea carruseles de fotos, menús desplegables y efectos visuales fluidos que hacen que la web resulte atractiva y moderna.
		
		**Hoy en día, JavaScript está en todas partes**
		
		Aunque nació para dar vida a las páginas web dentro del navegador, se ha vuelto tan popular que hoy se usa para construir **aplicaciones completas**.
		
		Por ejemplo, con herramientas basadas en JavaScript como **Node.js**, los servidores pueden procesar datos, y con tecnologías como **React Native** o **Electron**, se pueden programar aplicaciones móviles y de escritorio que usas a diario (como Discord, Spotify o Netflix).
