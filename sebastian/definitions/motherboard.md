La **placa base** (_motherboard_) es una **placa de circuito impreso que se utiliza como base de una computadora**: asigna energía y permite la comunicación entre los demás componentes internos — CPU, RAM y el resto del hardware. Es el sistema nervioso de la máquina: nada funciona sin estar conectado a ella.

#### Qué Hace

-  **Interconexión**: todos los componentes se conectan a ella — sockets, ranuras y puertos que determinan qué puede existir en la máquina.
-  **Distribución de energía**: la fuente alimenta a la placa y esta reparte tensiones reguladas a CPU, RAM, discos y periféricos.
-  **Comunicación**: sus buses (chipset incluido) transportan los datos entre procesador, memoria, almacenamiento y periféricos — el tráfico entero de la computadora pasa por aquí.
-  **Firmware propio**: aloja el BIOS/UEFI — el firmware que arranca y configura todo antes del sistema operativo.

#### Tipos y Compatibilidad

Existen varios tipos de placas base **diseñadas para funcionar con un tipo específico de procesador y memoria**: el socket del CPU y el tipo de RAM que admite son decisiones de compra que fijan el techo de la máquina — además del factor de forma (ATX, micro-ATX, mini-ITX) que define el tamaño del gabinete y las expansiones posibles.

#### Diferencia Crítica: Placa Base vs. CPU

-  La **CPU** procesa: es el cerebro que ejecuta las instrucciones.
-  La **placa base** conecta y alimenta: el sistema nervioso que permite al cerebro hablar con memoria, discos y periféricos.
-  El rendimiento del conjunto lo limita la más lenta de las conexiones: una CPU potente en una placa con buses antiguos corre atada — el componente "pasivo" decide cuánto rinde el activo.

### Propósito fundamental

La placa base es la plataforma sobre la que una computadora deja de ser una lista de piezas: asigna energía, transporta datos y fija qué se puede conectar — y su elección define el techo de todo lo demás — la verdad incómoda del hardware es que el componente que no calcula es el que decide hasta dónde puede calcular el que sí.
