
Un servicio centralizado de inicio de sesión único (SSO). Permite a los usuarios iniciar sesión una sola vez para acceder a múltiples cuentas de AWS y a aplicaciones empresariales externas (como Microsoft 365, Salesforce, etc.), simplificando la administración de accesos y la seguridad de la compañía.
