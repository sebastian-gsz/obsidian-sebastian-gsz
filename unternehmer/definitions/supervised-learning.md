Método de entrenamiento en el cual el algoritmo aprende a partir de un conjunto de datos "etiquetados" (labeled data). El sistema recibe pares de entrada y salida esperada, permitiendo que el modelo ajuste sus parámetros internos para minimizar el error entre su predicción y la respuesta correcta proporcionada por el supervisor.

* **Aplicación técnica**: En ciberseguridad, se utiliza para tareas de clasificación (como distinguir tráfico "seguro" de "malicioso"). El modelo aprende las características distintivas de cada categoría mediante la exposición continua a ejemplos ya clasificados, fortaleciendo su capacidad de generalización ante nuevos datos.
