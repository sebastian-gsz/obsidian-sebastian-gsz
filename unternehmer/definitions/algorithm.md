Secuencia finita, ordenada y no ambigua de instrucciones diseñadas para resolver un problema específico o realizar una tarea computacional.

-  **Propósito fundamental:** Automatizar la resolución de problemas mediante pasos claros, precisos y ejecutables, garantizando un resultado determinista a partir de una entrada dada.
-  **Propiedades clave:**
    
    -  **Finitud:** Debe finalizar tras un número determinado de pasos.
    -  **Definibilidad:** Cada paso debe estar claramente definido sin ambigüedad.
    -  **Entrada/Salida:** Define un conjunto de valores iniciales (input) y un resultado final (output).
-  **Facetas de aplicación:**
    
    -  **Programación:** Define la lógica de ejecución, el flujo de control (bucles, condicionales) y la manipulación eficiente de estructuras de datos.
    -  **Ciencia de Datos:** Implementa modelos matemáticos, algoritmos de aprendizaje automático (Machine Learning) y métodos estadísticos para realizar inferencias y predicciones.
