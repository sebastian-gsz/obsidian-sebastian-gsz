Un atributo es una unidad fundamental de información que define una propiedad, característica o estado de un objeto, entidad o estructura de datos. Actúa como el metadato esencial para describir la naturaleza y el contexto de una entidad dentro de cualquier sistema de información, permitiendo que sea procesada, identificada y manipulada de manera precisa.
