Modelo NoSQL simple donde cada elemento se almacena como un par de una clave única y su valor asociado.

* **Faceta de rendimiento**: Ofrece una latencia de lectura/escritura extremadamente baja (microsegundos).
* **Faceta de uso**: Ideal para caché de aplicaciones, gestión de sesiones de usuario o perfiles temporales.
* **Propósito**: Maximizar la velocidad de acceso mediante búsquedas directas por clave, sacrificando consultas complejas o relaciones entre datos.
