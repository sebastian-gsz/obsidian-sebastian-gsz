Proceso de traducción donde un software especializado (compilador) transforma el código fuente escrito en lenguajes de alto nivel (humanamente legibles) a lenguaje máquina (binario ejecutable).

* **Proceso**: El código se analiza, se optimiza y se traduce a instrucciones de bajo nivel (0s y 1s) que el procesador puede ejecutar directamente.
* **Diferencia clave**: A diferencia del *lenguaje interpretado* (que ejecuta código línea a línea al vuelo), la compilación genera un archivo ejecutable optimizado que se ejecuta a mayor velocidad.
