Almacena datos en formatos semiestructurados (JSON, BSON, XML) conocidos como documentos.

* **Faceta de flexibilidad**: Permite un esquema dinámico (schema-on-read), donde cada documento puede tener campos diferentes.
* **Faceta de desarrollo**: Se mapea casi directamente a los objetos de programación, facilitando el desarrollo rápido.
* **Propósito**: Gestionar datos con estructuras variables o jerárquicas, como catálogos de productos con atributos diversos o perfiles de usuario enriquecidos.
