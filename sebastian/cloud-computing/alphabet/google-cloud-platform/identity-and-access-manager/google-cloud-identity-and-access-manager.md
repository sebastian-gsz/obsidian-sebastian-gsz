**IAM (Identity and Access Management)** es donde controlas **quién puede hacer qué**. Es ideal para:

- Asignar permisos a **usuarios, grupos o cuentas de servicio**.
- Definir roles específicos (viewer, editor, admin, personalizados).
- Delegar acceso por niveles: organización, carpeta, proyecto, recurso.
