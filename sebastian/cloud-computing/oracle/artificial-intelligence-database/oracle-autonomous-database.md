Piensa en Oracle Autonomous Database como una versión de la Base de Datos Oracle que se gestiona a sí misma. La magia aquí es que utiliza inteligencia artificial y machine learning para **automatizar muchas tareas de administración** que tradicionalmente haría un DBA (administrador de base de datos), como:

-  Gestionar copias de seguridad.
-  Manejar la seguridad.
-  Optimizar el rendimiento.

**Autonomous Database** ofrece cuatro tipos de cargas de trabajo optimizadas:

-  **``Autonomous Transaction Processing``:** Para cargas de trabajo transaccionales (muchas operaciones pequeñas y rápidas).
-  **``Autonomous Data Warehouse``:** Para análisis y data warehousing (consultas rápidas sobre grandes volúmenes de datos).
-  **``Oracle APEX Application Development``:** ¡Aquí está! Optimizado específicamente para desarrollar aplicaciones con Oracle APEX.
-  **``Autonomous JSON Database``:** Para desarrollo de aplicaciones centrado en datos JSON.

La plataforma se posiciona como una **base de datos convergente**, diseñada para consolidar todas las cargas de trabajo (OLTP, IA, Analytics, JSON, etc.) en un único motor, eliminando la fragmentación arquitectónica.

1. **Operaciones autónomas (Zero-DBA)**

	La automatización mediante IA gestiona el ciclo de vida completo sin intervención humana:
	
	-  **Self-Tuning:** Optimización automática de índices y planes de ejecución.
	-  **Self-Self-Patching:** Aplicación de seguridad sin tiempos de inactividad.
	-  **Self-Scaling:** Escalado elástico de CPU y almacenamiento bajo demanda.
	-  **Resiliencia:** Backups automáticos y alta disponibilidad con conmutación por error.
2. **Capacidades estratégicas**

	-  **IA y Analytics:** Ejecución de modelos de _Machine Learning_ y analítica directamente sobre los datos, sin moverlos (evita latencia y riesgos de seguridad).
	-  **Desarrollo moderno:** Integración nativa con **Oracle APEX** (Low-Code) y exposición automática de APIs REST mediante **ORDS**.
	-  **Seguridad:** Cifrado _by default_ (en reposo y tránsito) con auditoría constante.
	-  **Estrategia Multi-Cloud:** Operabilidad extendida más allá de OCI, integrándose con entornos como Microsoft Azure y Google Cloud.
