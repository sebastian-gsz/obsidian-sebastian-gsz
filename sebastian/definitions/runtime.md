Un runtime es el "gestor" o "intérprete" que permite que tu código cobre vida. Cuando escribes un programa, este es solo texto estático. Para que haga algo, necesita a alguien que traduzca esas instrucciones a un lenguaje que el sistema operativo entienda y que gestione los recursos (memoria, CPU) mientras el programa corre.
